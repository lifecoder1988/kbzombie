# 键盘侠大战僵尸 - 游戏设计文档

> **目标用户**：小学三年级（8-9 岁）
> **核心理念**：在游戏中建立正确指法习惯，让孩子觉得"好玩"而非"被考试"
> **技术栈**：React + Canvas，桌面端浏览器，localStorage 存储

---

## 一、游戏概述

### 1.1 一句话描述

僵尸从右边走来，孩子打字触发植物攻击，连击越长激活的植物越多，结算时所有已激活植物联合攻击，打满整条连击链触发最强协同大招并复活阵亡植物。

### 1.2 视觉风格

- 植物大战僵尸经典风格，卡通蠢萌，不恐怖
- 横版草坪场景：左侧植物阵地，右侧僵尸进攻方向
- 僵尸头顶浮动显示字母/单词

### 1.3 核心循环

```
打字命中 → 连击推进植物链 → 结算时所有已激活植物联合攻击
    ↓                              ↓
  连击越长 → 激活植物越多 → 协同加成越强 → 攻击形态越丰富
    ↓
  打满链条 → 最强协同攻击 + 阵亡植物复活 + 存活植物回血
```

## 二、核心机制

### 2.1 打字攻击

- 僵尸从右侧缓慢走向左侧植物阵地
- 每只僵尸头顶显示字母或单词
- 按对字母 → 连击 +1，命中该僵尸
- 按错 → 触发一次结算（按当前已激活植物计算攻击），连击归零
- 按空格 → 主动触发结算，效果同上

### 2.2 连击与植物链条

#### 链条结构

植物从左到右排列，每棵植物占据一段连击区间。**每棵植物的段数由配置决定，不固定**。

```
示例（段数分别为 4、4、8）：
[豌豆射手:4段] → [寒冰射手:4段] → [火炬树桩:8段]
  连击 1-4          连击 5-8         连击 9-16
```

链条总长 = 各植物段数之和。

#### 连击推进规则

| 操作 | 效果 |
|------|------|
| 按对字母 | 连击 +1，推进到链条中对应的植物段 |
| 按错字母 | 触发结算攻击，连击归零 |
| 按空格 | 主动触发结算攻击，连击归零 |
| 连击打满链条 | 自动触发最强结算（全植物协同）+ 复活/回血，连击归零 |

#### 结算攻击计算

每次结算（按错/空格/打满）的攻击力 = **所有已激活的存活植物** 的攻击力之和 + 协同加成。

```
示例：链条 [豌豆:活] → [寒冰:活] → [火炬:活]
连击到第 10 下按错 →
  已激活: 豌豆(连击 1-4 ✓) + 寒冰(连击 5-8 ✓) + 火炬前 2 段(连击 9-10 ✓)
  结算 = 豌豆攻击力 + 寒冰攻击力 + 火炬攻击力 + 协同加成(豌豆+火炬→火焰豌豆)
  攻击范围/类型由协同规则决定
```

阵亡植物不贡献攻击力：

```
示例：链条 [豌豆:活] → [寒冰:活] → [火炬:☠️]
连击到第 10 下按错 →
  已激活: 豌豆(✓) + 寒冰(✓) + 火炬前 2 段(☠️ 无贡献)
  结算 = 豌豆攻击力 + 寒冰攻击力（火炬阵亡，不贡献攻击也不触发协同）
  火炬未复活（没打满空转段）
```

### 2.3 植物阵亡与复活

#### 植物血量

- 每棵植物有独立血量
- 僵尸到达植物位置后开始啃，持续扣血
- 血量归零 → 植物阵亡，僵尸继续前进啃下一棵
- 正在被啃的僵尸仍可被打字击杀，击杀后植物保住（残血）

#### 回血与复活

打满整条连击链时：

| 植物状态 | 效果 |
|----------|------|
| 存活（满血或残血） | 回血（回血量可配置） |
| 阵亡 | 复活（复活后的血量可配置） |

**关键规则**：复活的植物**不参与本次结算攻击**，从下次连击开始才贡献攻击力。存活植物正常参与本次结算。

#### 阵亡后的链条

植物阵亡后链条结构不变，阵亡植物的连击段变为"空转"：

- 连击数仍然正常增长
- 该段不产生攻击输出
- 不触发涉及该植物的协同效果
- 打满空转段可复活该植物

### 2.4 僵尸啃植物机制

植物从左到右排列，**最强植物在最右边（最靠近僵尸进攻方向）**。

```
僵尸从右往左啃：
僵尸 →→→ [大喷菇] → 啃掉 → [火炬树桩] → 啃掉 → [寒冰射手] → ...
          最强，最先被啃         ←  越往左越安全
```

- 僵尸到达植物位置后停下来啃，啃的过程中可被击杀
- 啃掉当前植物后继续前进到下一棵
- 啃穿整排所有植物并走出屏幕左侧 → 放过计数 +1

### 2.5 通关与失败

| 事件 | 后果 |
|------|------|
| 僵尸到达最右侧植物 | 开始啃，僵尸停下 |
| 啃掉一棵植物 | 继续前进啃下一棵 |
| 啃穿所有植物走出屏幕 | 放过计数 +1 |
| 放过数达到上限 | 本波失败，重打当前波 |
| 所有波次完成 | 关卡通关 |

**放过上限按难度档位配置**（同一难度下所有关卡一致）：

| 难度 | 放过上限 | 说明 |
|------|----------|------|
| 简单 | 可配置（建议 5） | 容错大，适合练习 |
| 普通 | 可配置（建议 3） | 标准体验 |
| 困难 | 可配置（建议 1） | 高手挑战 |

### 2.6 波次机制

- 每关包含多波僵尸（建议 3-5 波）
- 每波约 15-20 只僵尸，耗时约 2-3 分钟
- 一局总时长约 10-15 分钟

**波次之间**：

| 项目 | 是否重置 |
|------|----------|
| 连击进度 | 归零 |
| 放过计数 | 归零 |
| 植物血量 | **不恢复**，保持上一波结束时的状态 |
| 阵亡植物 | **不复活**，需在下一波通过打满连击复活 |

> 设计意图：前面打得好，后面有优势；前面打得差，后面压力更大。持续后果让每一波的表现都有意义。

## 三、多路系统

### 3.1 路数递进

| 阶段 | 路数 | 说明 |
|------|------|------|
| 初期 | 1 路 | 专注指法，不分心 |
| 中期 | 2 路 | 增加战场判断 |
| 后期 | 3 路 | 多线程注意力管理 |

### 3.2 每路独立

- 每路有自己的植物链条
- 连击进度独立
- 植物血量和生死状态独立
- A 路打满连击只影响 A 路的植物

### 3.3 操作方式

只有两个操作：

| 按键 | 功能 |
|------|------|
| 字母键 | 打字攻击，同时隐含选路 |
| 空格键 | 主动释放当前路连击（结算攻击，连击归零） |

**流程**：

1. 打字 → 系统匹配到对应路线（看哪路最前面的僵尸字母匹配）→ 连击推进该路
2. 想切路 → 按空格释放当前路 → 打下一个字母自动匹配到新路
3. 打满某路 → 自动结算，之后下一个字母自然选路

### 3.4 出题规则

- **各路最前面的僵尸字母互不重复**（避免歧义）
- 后面排队的僵尸字母可以重复（孩子当下只需关注最前面那只）
- 万一出现特殊情况的字母冲突 → 优先匹配当前路

### 3.5 打字匹配与攻击目标

- 默认攻击：命中当前路**最前面**的僵尸（最靠近植物的）
- 穿透/范围攻击（由协同规则触发）：可命中多只僵尸
- 攻击范围和类型完全由协同攻击规则配置

## 四、植物系统

### 4.1 植物属性

每棵植物有以下可配置属性：

```
植物 {
  id: string               // 唯一标识
  name: string             // 显示名称
  comboSegment: number     // 占据的连击段数（4、8、16...）
  attackPower: number      // 基础攻击力
  attackType: string       // 默认攻击类型（单体/穿透/范围...）
  hp: number               // 血量上限
  chainPosition: number    // 链条中的位置（从左到右）
  unlockStage: number      // 在哪个指法阶段解锁
}
```

### 4.2 初版植物设计

| 植物 | 链条位置 | 连击段数 | 攻击特点 | 解锁阶段 |
|------|----------|----------|----------|----------|
| 豌豆射手 | 第 1 位 | 4 | 单发直线，基础伤害 | 第 1 阶段（默认） |
| 寒冰射手 | 第 2 位 | 4 | 攻击附带减速效果 | 第 2 阶段 |
| 双发射手 | 第 3 位 | 4 | 两颗子弹同时发射 | 第 3 阶段 |
| 火炬树桩 | 第 4 位 | 8 | 火焰弹，高伤害 | 第 4 阶段 |
| 大喷菇 | 第 5 位 | 16 | 范围攻击，打一片 | 第 5 阶段 |

> 段数和属性均为初版建议值，由策略配置决定，可随时调整。

### 4.3 植物排列

**最强植物在最右边（最靠近僵尸）**。链条从左到右依次是从弱到强。

```
← 安全侧                              危险侧 →
[豌豆射手] → [寒冰射手] → [双发射手] → [火炬树桩] → [大喷菇]
  最弱，最安全                            最强，最先被啃
```

初版按解锁顺序固定排列。**后续可扩展**：让孩子自定义植物顺序，增加策略深度。

### 4.4 协同攻击系统

#### 触发时机

**每次结算都判断协同**。只要结算时已激活的存活植物满足协同条件，就触发对应效果。

#### 协同规则结构

```
协同规则 {
  id: string                    // 唯一标识
  name: string                  // 协同名称（如"火焰豌豆"）
  requiredPlants: string[]      // 需要哪些植物同时激活且存活
  attackPowerBonus: number      // 攻击力加成（百分比或固定值）
  attackTypeOverride: string    // 改变攻击类型（穿透/范围/全行爆炸等）
  attackRange: object           // 攻击范围参数（半径、宽度等）
  visualEffect: string          // 视觉特效标识
}
```

#### 初版协同设计

| 协同名称 | 所需植物 | 效果 |
|----------|----------|------|
| 火焰豌豆 | 豌豆射手 + 火炬树桩 | 攻击力加成，单体高伤 |
| 双发冰弹 | 寒冰射手 + 双发射手 | 两颗冰弹，减速范围扩大 |
| 火焰穿透 | 豌豆射手 + 火炬树桩 + 大喷菇 | 穿透攻击，打穿一排 |
| 全面轰炸 | 全部 5 棵植物 | 全行爆炸，清屏 |

> 协同规则通过策略配置管理，可随时新增、修改、删除，不改动核心代码。

### 4.5 结算攻击的完整计算流程

```
结算触发（按错 / 空格 / 打满）
  ↓
1. 确定已激活植物列表（连击经过且存活的植物）
  ↓
2. 计算基础攻击力 = 所有已激活存活植物的攻击力之和
  ↓
3. 匹配协同规则：检查已激活存活植物的组合，匹配所有满足条件的协同
  ↓
4. 应用协同加成：攻击力加成叠加，攻击类型取最高优先级的协同规则
  ↓
5. 确定攻击目标：根据最终攻击类型和范围，确定命中哪些僵尸
  ↓
6. 执行攻击：对目标僵尸造成伤害
  ↓
7. 如果是打满链条：额外触发存活植物回血 + 阵亡植物复活
   （复活的植物不参与上面第 1-6 步的攻击）
```

## 五、僵尸系统

### 5.1 僵尸属性

```
僵尸 {
  id: string            // 唯一标识
  type: string          // 类型
  hp: number            // 血量
  speed: number         // 移动速度
  chewSpeed: number     // 啃植物速度（每秒扣多少血）
  letters: string       // 头顶显示的字母/单词
  reward: object        // 击杀奖励（可扩展）
}
```

### 5.2 初版僵尸类型

| 僵尸类型 | 字母需求 | 血量 | 速度 | 啃速 | 解锁时机 |
|----------|----------|------|------|------|----------|
| 普通僵尸 | 1 个字母 | 低 | 慢 | 慢 | 初始 |
| 胖僵尸 | 2-3 个字母 | 高 | 慢 | 慢 | 第 2 阶段 |
| 旗手僵尸 | 1 个字母 | 低 | 稍快 | 快 | 第 3 阶段 |
| 单词僵尸 | 完整单词 | 中 | 中 | 中 | 第 5 阶段 |

> 更多僵尸类型可通过策略配置新增，不改动核心代码。

### 5.3 僵尸行为

```
生成（右侧屏幕外）
  ↓
向左移动（显示头顶字母）
  ↓
到达最右侧植物 → 停下来啃
  ↓
啃掉当前植物（血量归零）→ 继续前进啃下一棵
  ↓
啃穿所有植物 → 走出屏幕左侧 → 放过 +1
```

在任何阶段（移动中、啃植物中）都可以被打字击杀。

### 5.4 多字母/单词僵尸的打字规则

- 胖僵尸（2-3 个字母）：需要连续按对所有字母才消灭，按错中间任何一个字母则该僵尸的输入进度重置（但连击照常结算）
- 单词僵尸：同上，需要打完整个单词

## 六、指法阶段与进度系统

### 6.1 阶段设计

| 阶段 | 练习内容 | 解锁植物 | 路数 | 新增僵尸 |
|------|----------|----------|------|----------|
| 第 1 阶段 | 基准键 F / J | 豌豆射手（默认） | 1 路 | 普通僵尸 |
| 第 2 阶段 | 中间行 ASDF JKL; | 寒冰射手 | 1 路 | 胖僵尸 |
| 第 3 阶段 | 上行 QWER UIOP | 双发射手 | 1 路 | 旗手僵尸 |
| 第 4 阶段 | 下行 ZXCV NM | 火炬树桩 | 2 路 | — |
| 第 5 阶段 | 全键盘混合 | 大喷菇 | 3 路 | 单词僵尸 |
| 第 6 阶段 | 简单单词 | 待设计 | 3 路 | 长单词僵尸 |
| 第 7 阶段 | 短句 / 拼音 | 待设计 | 3 路 | 待设计 |

### 6.2 通关规则

- 每阶段包含固定数量的关卡（具体数值由策略配置）
- 通关所有关卡 → 进入下一阶段，解锁新植物
- 本波失败 → 重打当前波（不丢全局阶段进度）

### 6.3 核心成长循环

```
通关阶段 → 解锁新植物 → 链条加长，连击上限提升
                            ↓
                     协同组合更丰富 → 攻击形态更多样
                            ↓
                     但僵尸也更强 → 需要更好的指法和策略
```

## 七、指法引导系统

- 屏幕下方显示虚拟键盘
- 高亮当前需要按的键位
- 用颜色或图标指示应该用哪根手指
- 高阶阶段可关闭键盘提示（孩子主动设置或到一定阶段自动隐藏）

---

## 八、难度自适应（后续迭代）

初版：随机出当前阶段范围内的字母。

后续迭代方向：

- 为每个字母/单词维护熟练度分数
- 不熟悉的字母出现频率更高
- 已掌握的字母降低频率但不完全消失
- 具体算法待核心机制跑通后设计

## 九、反馈与激励

### 9.1 即时反馈（每次按键）

| 事件 | 反馈 |
|------|------|
| 按对字母 | 对应植物发射子弹动画 + 命中音效 + 僵尸受击 |
| 连击推进到新植物 | 植物切换特效 + 音效变化 |
| 结算攻击 | 所有已激活植物联合射击动画 |
| 协同触发 | 协同专属特效（火焰、冰霜、爆炸等） |
| 打满链条 | 全屏大招特效 + 复活/回血动画 |
| 按错 | 结算当前威力 + 连击条归零动画 |
| 僵尸啃植物 | 植物摇晃 + 血条下降 |
| 植物阵亡 | 植物碎裂/枯萎动画 |

### 9.2 短期反馈（每波结束）

- 本波数据：消灭数、最长连击、协同触发次数、放过数
- 趣味称号：「连击大师」「一个都没漏」「协同达人」
- 手指热力图：哪些手指表现好 / 需要加油

### 9.3 长期反馈

- 解锁新植物（最核心的长期动力）
- 成就徽章墙
- 植物图鉴
- **不设断签惩罚**：几天没玩进度不倒退

## 十、技术架构

### 10.1 技术栈

| 维度 | 方案 |
|------|------|
| 框架 | React（单页应用） |
| 渲染 | Canvas（横版游戏场景）+ DOM（UI 层） |
| 音效 | Web Audio API（初版简单音效） |
| 数据存储 | 浏览器 localStorage |
| 键盘输入 | keydown 事件（需处理中文输入法干扰） |
| 适配 | 仅桌面端（需实体键盘） |

### 10.2 架构原则：机制与策略分离

```
┌─────────────────────────────────────────────────┐
│                  策略配置层                        │
│  关卡数据 / 波次配置 / 植物属性 / 僵尸属性         │
│  协同规则 / 难度参数 / 字母出现规则                 │
```

**新增内容不改核心代码**：

- 新植物 → 加一条植物配置
- 新僵尸 → 加一条僵尸配置
- 新协同 → 加一条协同规则
- 调数值 → 改配置参数

### 10.3 核心数据模型

#### 游戏状态

```
GameState {
  currentStage: number          // 当前指法阶段
  currentLevel: number          // 当前关卡
  currentWave: number           // 当前波次
  difficulty: string            // 难度档位
  lanes: Lane[]                 // 各路状态
  missedCount: number           // 当前波放过数
  missedLimit: number           // 放过上限
  zombies: Zombie[]             // 场上所有僵尸
  waveStatus: string            // playing / waveComplete / levelComplete / failed
}
```

#### 单路状态

```
Lane {
  id: number
  plants: PlantInstance[]       // 该路的植物链条
  comboCount: number            // 当前连击数
  comboMax: number              // 连击上限（= 链条中所有植物段数之和）
}
```

#### 植物实例

```
PlantInstance {
  plantId: string               // 植物类型 ID
  position: number              // 链条中的位置
  comboStart: number            // 连击段起始（如第 5 下）
  comboEnd: number              // 连击段结束（如第 8 下）
  currentHp: number             // 当前血量
  maxHp: number                 // 血量上限
  alive: boolean                // 是否存活
}
```

#### 持久化存储

```
SaveData {
  unlockedStage: number         // 已解锁到第几阶段
  stageProgress: {              // 每阶段通关进度
    [stageId]: {
      completedLevels: number[]
    }
  }
  difficulty: string            // 玩家选择的难度
  statistics: {                 // 统计数据
    totalZombiesKilled: number
    longestCombo: number
    totalPlayTime: number
    ...
  }
  achievements: string[]        // 已达成的成就
}
```

## 十一、实现优先级

### P0 - 最小可玩版本

| 模块 | 内容 | 完成标准 |
|------|------|----------|
| 单路僵尸 + 打字攻击 | 僵尸走来，打字击杀 | 能打字消灭僵尸 |
| 植物链条 + 连击系统 | 可变段数链条，连击推进 | 连击正确推进，按错/空格正确结算 |
| 结算攻击计算 | 已激活植物攻击力求和 | 攻击力正确计算 |
| 僵尸啃植物 | 植物血量，啃→阵亡→继续 | 僵尸能啃穿植物链 |
| 植物复活/回血 | 打满链条触发 | 复活和回血正确执行 |
| 指法提示 | 虚拟键盘高亮 | 能看到该按哪个键 |
| 波次基础流程 | 开始→打完→下一波/失败 | 能完整打完一关 |

### P1 - 核心体验完善

| 模块 | 内容 |
|------|------|
| 协同攻击系统 | 植物组合判断 + 攻击类型变化 |
| 即时反馈 | 音效 + 命中特效 + 连击切换动画 |
| 波次总结 | 每波结束展示数据和称号 |
| 多种攻击类型 | 单体/穿透/范围/全行爆炸 |

### P2 - 难度与深度

| 模块 | 内容 |
|------|------|
| 多路系统 | 2 路、3 路，独立链条 |
| 难度档位 | 简单/普通/困难，放过上限配置 |
| 自适应难度 | 字母出现频率智能调整 |
| 僵尸类型丰富化 | 胖僵尸、旗手、单词僵尸 |

### P3 - 长期动力

| 模块 | 内容 |
|------|------|
| 植物解锁 + 图鉴 | 通关解锁，收集展示 |
| 成就系统 | 各种里程碑徽章 |
| 植物自定义排列 | 让孩子选择植物顺序 |
| 更多协同规则 | 丰富组合变化 |
