# 键盘侠大战僵尸 - 游戏设计文档

> **目标用户**：小学三年级（8-9 岁）
> **核心理念**：在游戏中建立正确指法习惯，让孩子觉得"好玩"而非"被考试"
> **技术栈**：React + Canvas，桌面端浏览器，localStorage 存储

---

## 一、游戏概述

### 1.1 一句话描述

僵尸从右边走来，孩子打字触发植物攻击，连击越长激活的植物越多，结算时所有已激活植物联合攻击，打满整条连击链触发最强协同大招并复活阵亡植物。

### 1.2 视觉风格

- 植物大战僵尸经典风格，卡通蠢萌，不恐怖
- 横版草坪场景：左侧植物阵地，右侧僵尸进攻方向
- 当前连击位置的植物上方显示待输入的字母/单词

### 1.3 核心循环

```
打字命中 → 连击推进植物链 → 结算时所有已激活植物联合攻击
    ↓                              ↓
  连击越长 → 激活植物越多 → 协同加成越强 → 攻击形态越丰富
    ↓
  打满链条 → 最强协同攻击 + 阵亡植物复活 + 存活植物回血
```

## 二、核心机制

### 2.1 打字攻击

- 僵尸从右侧缓慢走向左侧植物阵地
- 当前连击位置的植物上方显示待输入的字母（由出题系统按当前阶段的字母池生成）
- 按对字母 → 连击 +1，链条推进，下一个字母出现在对应植物上方
- 按错 → 触发一次结算（按当前已激活植物计算攻击），连击归零
- 按空格 → 主动触发结算，效果同上
- 结算触发后，已激活植物**发射弹道攻击**，弹道飞行一段时间后命中僵尸（非瞬时伤害）
- 默认命中当前路最前面的僵尸；穿透/范围攻击可命中多只（见攻击类型框架）
- 弹道飞行期间僵尸继续移动和啃食
- **弹道飞行期间玩家可以继续打字**，多组弹道可同时在空中飞行
- 每次结算的目标按**发射时的场上状态**快照选择，不等前一发命中

#### 有效输入规则

| 按键类型 | 处理方式 |
|----------|----------|
| 当前字母池内的字母 | 正常匹配，按对推进连击，按错触发结算 |
| 字母池外的可见字符 | 视为按错，触发结算 |
| 空格 | 主动触发结算 |
| 功能键（Shift/Ctrl/Alt 等） | 忽略，不产生任何效果 |
| 连击为 0 时按错 | 忽略，不触发空结算 |
| 场上无僵尸时结算 | 正常结算流程但弹道无目标，连击归零（不浪费结算动画） |

> 初版只接受字母键。后续高阶阶段可扩展数字和符号。

### 2.2 连击与植物链条

#### 链条结构

植物从左到右排列，每棵植物占据一段连击区间。**每棵植物的段数由配置决定，不固定**。

```
示例（段数分别为 4、4、8）：
[豌豆射手:4段] → [寒冰射手:4段] → [火炬树桩:8段]
  连击 1-4          连击 5-8         连击 9-16
```

链条总长 = 各植物段数之和。

#### 连击推进规则

| 操作 | 效果 |
|------|------|
| 按对字母 | 连击 +1，推进到链条中对应的植物段 |
| 按错字母（连击 > 0） | 触发结算攻击，连击归零 |
| 按错字母（连击 = 0） | 忽略，不触发空结算 |
| 按空格（连击 > 0） | 主动触发结算攻击，连击归零 |
| 按空格（连击 = 0） | 忽略 |
| 连击打满链条 | 自动触发最强结算（全植物协同）+ 复活/回血，连击归零 |

#### 结算攻击计算

每次结算（按错/空格/打满）的攻击力 = **所有已激活的存活植物** 的攻击力之和 + 协同加成。

**激活条件：连击打满该植物的全部段数**。仅仅"经过"但未打满的植物不算激活，不贡献攻击力。这意味着中途按错会浪费未打满植物的进度，鼓励玩家尽量多打再结算。

```
示例：链条 [豌豆:4段] → [寒冰:4段] → [火炬:8段]
连击到第 10 下按错 →
  豌豆(4/4 满 ✓) + 寒冰(4/4 满 ✓) + 火炬(2/8 未满 ✗)
  已激活: 豌豆 + 寒冰（火炬未打满，不参与）
  结算 = 豌豆攻击力 + 寒冰攻击力 + 协同加成

连击到第 6 下按错 →
  豌豆(4/4 满 ✓) + 寒冰(2/4 未满 ✗)
  已激活: 仅豌豆（寒冰未打满，不参与）
  结算 = 豌豆攻击力（无协同，只有 1 棵）
```

阵亡植物不贡献攻击力（即使打满了也不算）：

```
示例：链条 [豌豆:活] → [寒冰:活] → [火炬:☠️]
连击到第 16 下打满 →
  豌豆(4/4 满, 活 ✓) + 寒冰(4/4 满, 活 ✓) + 火炬(8/8 满, ☠️ 无贡献)
  结算 = 豌豆攻击力 + 寒冰攻击力（火炬阵亡，不贡献攻击也不触发协同）
  打满后火炬复活，但不参与本次结算
```

### 2.3 植物阵亡与复活

#### 植物血量

- 每棵植物有独立血量
- 僵尸到达植物位置后开始啃，持续扣血
- 血量归零 → 植物阵亡，僵尸继续前进啃下一棵
- 正在被啃的僵尸仍可被打字击杀，击杀后植物保住（残血）

#### 回血与复活

打满整条连击链时：

| 植物状态 | 效果 |
|----------|------|
| 存活（满血或残血） | 回血（回血量可配置） |
| 阵亡 | 复活（复活后的血量可配置） |

**关键规则**：复活的植物**不参与本次结算攻击**，从下次连击开始才贡献攻击力。存活植物正常参与本次结算。

#### 阵亡后的链条

植物阵亡后链条结构不变，阵亡植物的连击段变为"空转"：

- 阵亡植物呈**倒伏/枯萎**状态，但仍占据链条位置
- 该植物上方**仍然显示待输入字母**，玩家仍需正确输入才能推进连击
- 连击数仍然正常增长
- 该段不产生攻击输出
- 不触发涉及该植物的协同效果
- 打满整条链条可复活该植物（视觉上用灰色/半透明字母暗示"空转"）

### 2.4 僵尸啃植物机制

植物从左到右排列，**最强植物在最右边（最靠近僵尸进攻方向）**。

```
僵尸从右往左啃：
僵尸 →→→ [大喷菇] → 啃掉 → [火炬树桩] → 啃掉 → [寒冰射手] → ...
          最强，最先被啃         ←  越往左越安全
```

- 僵尸到达植物位置后停下来啃，啃的过程中可被击杀
- **多只僵尸可以同时啃同一棵植物**，植物承受的伤害叠加（DPS 翻倍）
- 啃掉当前植物后继续前进到下一棵
- 啃穿整排所有植物并走出屏幕左侧 → 放过计数 +1

### 2.5 通关与失败

| 事件 | 后果 |
|------|------|
| 僵尸到达最右侧植物 | 开始啃，僵尸停下 |
| 啃掉一棵植物 | 继续前进啃下一棵 |
| 啃穿所有植物走出屏幕 | 放过计数 +1 |
| 放过数达到上限 | **本关失败，重打当前关**（所有植物状态重置为满血） |
| 所有波次完成 | 关卡通关 |

> 设计意图：重打整关而非当前波，避免因累积植物损伤造成无法翻盘的死局。通过控制每关波次数量（建议 3-5 波）来控制单次失败的时间成本。

**放过上限按难度档位配置**（同一难度下所有关卡一致）：

| 难度 | 放过上限 | 说明 |
|------|----------|------|
| 简单 | 可配置（建议 5） | 容错大，适合练习 |
| 普通 | 可配置（建议 3） | 标准体验 |
| 困难 | 可配置（建议 1） | 高手挑战 |

### 2.6 波次机制

- 每关包含多波僵尸（建议 3-5 波）
- 每波约 15-20 只僵尸，耗时约 2-3 分钟
- 一局总时长约 10-15 分钟

**波次之间**：

| 项目 | 是否重置 |
|------|----------|
| 连击进度 | 归零 |
| 放过计数 | **不归零**，整关累计 |
| 植物血量 | **不恢复**，保持上一波结束时的状态 |
| 阵亡植物 | **不复活**，需在下一波通过打满连击复活 |

> 设计意图：前面打得好，后面有优势；前面打得差，后面压力更大。持续后果让每一波的表现都有意义。

**波次过渡**：

- 波次之间有短暂停顿（具体秒数待定）
- 停顿期间可显示本波简要数据（消灭数、最长连击等）
- 停顿结束后自动进入下一波

> 过渡停顿给孩子喘息空间，也是正反馈时刻。具体时长和展示内容后续迭代确定。

## 三、多路系统

### 3.1 路数递进

| 阶段 | 路数 | 说明 |
|------|------|------|
| 初期 | 1 路 | 专注指法，不分心 |
| 中期 | 2 路 | 增加战场判断 |
| 后期 | 3 路 | 多线程注意力管理 |

### 3.2 每路独立

- 每路有**自己独立的植物链条**（玩家自选植物组合，各路可不同，各自独立状态）
- 连击进度独立
- 植物血量和生死状态独立
- 字母序列独立（同种植物在不同路或同路内重复放置，各自有独立字母）
- A 路打满连击只影响 A 路的植物
- **空路允许**：玩家可以选择不在某路放置植物，该路仍会生成僵尸，玩家需依靠跨路攻击（追踪/辐射弹道）清理或承担放过风险

### 3.3 操作方式与选路规则

只有两个操作：

| 按键 | 功能 |
|------|------|
| 字母键 | 打字攻击，同时隐含选路 |
| 空格键 | 主动释放**当前路**连击（仅结算当前路，连击归零） |

**"当前路"定义**：最近一次成功推进连击的那条路。初始状态无当前路。

#### 锁定模式

一旦匹配到某路，该路被**锁定为当前路**，后续按键只看当前路的字母，不再匹配其他路。直到结算（按错/空格/打满）解除锁定。

**完整流程**：

```
无当前路（自由匹配状态）：
  按字母 → 匹配到某路当前字母 → 锁定该路，推进连击
  按字母 → 不匹配任何路 → 忽略
  按空格 → 忽略

有当前路（锁定状态）：
  按字母 → 匹配当前路字母 → 推进连击
  按字母 → 不匹配当前路 → 触发当前路结算，连击归零，字母重置，解除锁定
  按空格 → 触发当前路结算，连击归零，字母重置，解除锁定
  打满当前路 → 自动结算，连击归零，字母重置，解除锁定
```

**操作示例**：

1. 各路当前连击位置的植物各自显示一个待输入字母
2. 孩子打字 → 系统匹配到显示该字母的那路 → 锁定该路，连击推进
3. 继续打字 → 只看当前路字母
4. 想切路 → 按空格释放当前路 → 回到自由匹配状态 → 打下一个字母自动匹配到新路
5. 打满某路 → 自动结算，回到自由匹配状态

**当前路通过连击字母颜色自然区分**，锁定路的字母显示为高亮色，未锁定路的字母保持普通色。

### 3.4 出题规则

- **无当前路时，各路当前待输入字母互不重复**（避免自由匹配状态下的歧义）
- 锁定状态下，其他路的字母与当前路重复不影响（因为按键只看当前路）
- 结算后该路字母全部重新生成，生成时检查不与其他路的当前字母冲突
- 字母由出题系统按当前阶段的字母池生成，显示在对应植物上方

### 3.5 僵尸分配

- 波次内僵尸**随机分配到各路**（包括空路）
- 各路僵尸独立移动、独立啃植物

### 3.6 结算攻击目标

弹道的命中范围由 Flight 和 Impact 维度共同决定：

- **straight + vanish**：水平直线，命中当前路最前面的僵尸，不跨路
- **straight + pierce**：水平直线穿透，命中当前路直线上所有僵尸
- **straight + chain**：命中后弹向附近僵尸，可跨路
- **straight + explode**：命中后落点范围爆炸，可波及邻路
- **tracking + 任意 Impact**：追踪弹锁定全局最近僵尸，可跨路
- **fan（扇形散射）**：子弹可飞入邻路，可跨路

碰撞检测保持全局，由弹道物理自然决定命中范围。攻击类型由四维特效合成系统自动合成（见 4.4 特效系统）。

## 四、植物系统

### 4.1 植物属性

每棵植物有以下可配置属性：

```
植物 {
  id: string               // 唯一标识
  name: string             // 显示名称
  comboSegment: number     // 占据的连击段数（4、8、16...）
  attackPower: number      // 基础攻击力
  element: Element         // 元素效果（normal / ice / fire / electric / stun / knockback）
  spread: Spread           // 发射模式（single / burst / fan）
  flight: Flight           // 飞行路径（straight / tracking）
  impact: Impact           // 命中行为（vanish / chain / pierce / explode）
  hp: number               // 血量上限
  chainPosition: number    // 链条中的位置（从左到右）
  unlockStage: number      // 在哪个指法阶段解锁
}
```

### 4.2 初版植物设计

| # | 植物 | 段数 | 元素 | 发射 | 飞行 | 命中 | 特色定位 | 解锁阶段 |
|---|------|------|------|------|------|------|----------|---------|
| 1 | 豌豆射手 | 4 | normal | single | straight | vanish | 基础款，零门槛 | 1 |
| 2 | 寒冰射手 | 4 | ice | single | straight | vanish | 入门元素：减速 | 2 |
| 3 | 双发射手 | 4 | normal | burst | straight | vanish | 入门发射：连发 | 3 |
| 4 | 火炬树桩 | 8 | fire | single | straight | vanish | 冰火互斥策略入门 | 4 |
| 5 | 仙人掌 | 4 | normal | single | straight | pierce | 入门命中：穿透 | 5 |
| 6 | 闪电芦苇 | 4 | electric | single | straight | vanish | 入门电击：僵尸扎堆时强 | 6 |
| 7 | 玉米投手 | 8 | stun | single | straight | explode | 眩晕+落点爆炸，控制型 | 7 |
| 8 | 大喷菇 | 16 | normal | fan | straight | vanish | 高段数高回报：扇形散射 | 8 |
| 9 | 猫尾草 | 8 | normal | single | tracking | chain | 跨路追踪+弹跳 | 9 |
| 10 | 飓风花 | 8 | knockback | single | straight | vanish | 击退争取时间 | 10 |
| 11 | 西瓜投手 | 12 | normal | single | straight | explode | 高段数：大范围爆炸 | 11 |
| 12 | 星星果 | 12 | electric | fan | tracking | vanish | 终极多维：电击+扇形+追踪 | 12 |

**设计节奏**：
- **阶段 1-6（4 段为主）**：每棵植物只在 1 个维度非默认，逐步教会孩子每个维度的含义
- **阶段 7-9（8 段）**：出现单棵多维度升级的植物（玉米投手 stun+explode、猫尾草 tracking+chain）
- **阶段 10-12（8-12 段）**：高投入高回报，星星果贡献 3 个维度

> 段数和属性均为初版建议值，由策略配置决定，可随时调整。

### 4.3 植物排列与 Slot 机制

#### Slot 槽

每路有一个 **slot 槽**，总长度是玩家的持久化状态值。植物的 `comboSegment` 即为其占用的 slot 长度。

```
slot 总长度 = 玩家当前 slotSize（初始值 4，通关奖励可增加）

规则：
- 放入植物的 comboSegment 总和 ≤ slot 长度
- 可以不填满（剩余空间留空）
- 同一植物可重复放置
- 只能选择已解锁的植物
- 每路可以放不同的植物组合
- 每关开始前选择，关内不可调整
```

#### 排列顺序

**玩家自由决定链条中植物从左到右的排列顺序**。右侧最靠近僵尸，最先被啃。

```
示例：玩家 slotSize = 12

路 A: [豌豆(4)] → [寒冰(4)] → [豌豆(4)]  = 12 ✓（重复植物）
路 B: [火炬(8)]                            = 8  ✓（不填满）
路 C:（空路）                               = 0  ✓（僵尸照走，靠跨路攻击清理）
```

#### Slot 值变化

- slotSize 是玩家的**持久化状态**（存在 SaveData 中）
- 不与具体阶段/关卡硬绑定
- 关卡通关奖励可包含 slot 值增加（由奖励配置驱动）
- 初始 slotSize = 4（只能放一棵 4 段植物）

### 4.4 特效系统

每棵植物自带特效标签，协同时特效按分类规则叠加，自动产生组合攻击效果，**无需穷举配置具体植物组合**。

#### 特效分类

特效分为**四个正交维度**，不同维度之间自由叠加，同维度内互斥取优：

| 维度 | 说明 | 可选值 |
|------|------|--------|
| **元素 Element**（命中后给僵尸施加的状态） | 冰+火互斥抵消，其余取优先级最高 | normal / ice / fire / electric / stun / knockback |
| **发射模式 Spread**（弹道发射形态） | 取优先级最高 | single / burst / fan |
| **飞行路径 Flight**（弹道飞行方式） | 取优先级最高 | straight / tracking |
| **命中行为 Impact**（弹道命中后处理） | 取优先级最高 | vanish / chain / pierce / explode |

四个维度完全正交，组合空间 6×3×2×4 = 144 种理论形态。加新植物 = 加特效标签，自动参与协同，不需要配置具体组合。

#### 同维度优先级

**元素优先级**（从低到高）：

```
普通(normal) < 冰冻(ice) = 火焰(fire) < 电击(electric) < 眩晕(stun) < 击退(knockback)
```

特殊规则：冰冻 + 火焰同时存在 → **互相抵消**，移除冰和火后取剩余最高优先级；若无剩余则回退为 normal。

**发射模式优先级**（从低到高）：

```
单发(single) < 连发(burst) < 扇形散射(fan)
```

**飞行路径优先级**（从低到高）：

```
直线(straight) < 追踪(tracking)
```

**命中行为优先级**（从低到高）：

```
消失(vanish) < 连锁跳跃(chain) < 穿透(pierce) < 落点爆炸(explode)
```

#### 元素效果详细行为

| 元素 | 命中后行为 | 关键参数 |
|------|-----------|---------|
| normal | 纯伤害，无附加 | — |
| ice | 减速（移动和啃食速度降低） | slowRatio（减速比例）、slowDuration（持续秒数） |
| fire | 灼烧（持续伤害） | burnDps（每秒伤害）、burnDuration（持续秒数） |
| electric | 电击（沿僵尸连通性传导伤害） | conductRadius（导电距离）、conductDamageDecay（每跳衰减比例）、conductMaxJumps（最大传导次数） |
| stun | 眩晕（完全停止移动和啃食） | stunDuration（持续秒数） |
| knockback | 击退（向右推回一段距离） | knockbackDistance（推回距离） |

**电击传导机制**：命中僵尸 A 后，从 A 开始检查周围 conductRadius 内的僵尸 B，B 受到弹道伤害 × conductDamageDecay 的伤害；B 周围再查 C，伤害继续衰减；最多传导 conductMaxJumps 次，每只僵尸只被传导一次（防环路）。传导是瞬时的，不创建新弹道实体。

**击退**是一次性位移，不是持续状态。其他状态效果（slow/burn/stun）同种不叠加、刷新持续时间，不同种可共存。

> 附加效果的具体数值待平衡调整时确定。

#### 弹道生命周期

弹道是**真实的游戏实体**，有位置、速度、碰撞体积，由引擎的实体系统管理生命周期，每帧参与 update/render 循环。

弹道生命周期分三个阶段，由 Spread / Flight / Impact 三个维度分别控制：

```
发射阶段（Spread 决定）→ 飞行阶段（Flight 决定）→ 命中阶段（Impact + Element 决定）
```

#### 发射阶段（Spread 决定）

| Spread | 创建逻辑 |
|--------|---------|
| single | 每棵植物发射 1 颗弹道，正前方 |
| burst | 每棵植物快速连发 N 颗（`burstCount`），同方向，按 `burstInterval` 间隔依次发射 |
| fan | 每棵植物扇形散射 N 颗（`fanBulletCount`），同时发射，均匀分布在 `fanSpreadAngle` 角度内，正前方必有一颗 |

burst 和 fan 创建的每颗子弹都是独立弹道实体，各自进入飞行和命中阶段。

#### 飞行阶段（Flight 决定）

| Flight | update 逻辑 |
|--------|------------|
| straight | 沿初始方向匀速直线飞行，飞出屏幕则消失 |
| tracking | 每帧调整飞行方向朝向目标（受 `trackingTurnRate` 限制），目标死亡后沿最后方向继续飞行 |

与 Spread 的组合自然生效：
- fan + tracking = 扇形射出的每颗子弹各自追踪最近目标
- burst + tracking = 连发的每颗子弹各自追踪（前一颗命中后可能追不同目标）

#### 命中阶段（Impact + Element 决定）

碰撞检测命中僵尸后：

| Impact | 命中后行为 |
|--------|-----------|
| vanish | 弹道消失 |
| chain | 在 `chainRange` 内找下一只未命中的僵尸，改变方向飞向它，弹跳次数 +1，达到 `chainBounces` 则消失 |
| pierce | 记录已命中僵尸（hitSet），弹道继续飞行，遇到新僵尸继续命中，每只僵尸只命中一次 |
| explode | 弹道消失，落点 `explodeRadius` 范围内所有僵尸受到 damage × `explodeDamageRatio` 伤害 |

**每次命中（包括 chain/pierce 的多次命中）都触发 Element 效果。**

#### 碰撞判定

- 弹道和僵尸都有碰撞体积（矩形 AABB）
- 每帧检测弹道与僵尸的碰撞（引擎层通用能力，不感知具体玩法）
- 命中后对该僵尸独立计算伤害，超杀不溢出
- 同一只僵尸可被多发弹道命中（来自不同次结算的弹道）

#### 特效合成示例

| 激活植物 | 元素 | 发射 | 飞行 | 命中 | 最终形态 |
|---------|------|------|------|------|---------|
| 豌豆 | normal | single | straight | vanish | 普通单发直射（基础攻击） |
| 寒冰 + 大喷菇 | ice | fan | straight | vanish | **冰冻扇形散射** |
| 火炬 + 猫尾草 | fire | single | tracking | chain | **火焰追踪连锁弹** |
| 寒冰 + 火炬 + 闪电芦苇 | 冰火抵消→electric | single | straight | vanish | **电击弹** |
| 寒冰 + 火炬 | 冰火抵消→normal | single | straight | vanish | **普通弹**（元素浪费） |
| 仙人掌 + 猫尾草 | normal | single | tracking | pierce>chain | **追踪穿透弹** |
| 玉米投手 + 大喷菇 + 猫尾草 | stun | fan | tracking | explode>chain | **眩晕追踪扇形爆炸** |
| 闪电芦苇 + 仙人掌 + 大喷菇 | electric | fan | straight | pierce | **电击扇形穿透弹** |

### 4.5 协同攻击系统

#### 触发条件

结算时激活了 **2 棵及以上存活植物**即触发协同。单棵植物结算只使用自身特效，不算协同。

#### 协同效果（两层）

**第一层：攻击力加成** — 由激活植物数量决定，与具体植物种类无关：

| 激活植物数 | 攻击力倍率 |
|-----------|-----------|
| 1 棵 | ×1.0（无加成） |
| 2 棵 | ×待定（建议 1.2） |
| 3 棵 | ×待定（建议 1.5） |
| 4 棵 | ×待定（建议 1.8） |
| 5 棵 | ×待定（建议 2.2） |
| 6 棵（满链） | ×待定（建议 3.0） |

> 倍率公式待平衡调整时确定。可以是固定查表，也可以是连续公式。

**第二层：特效合成** — 收集所有已激活存活植物的四维特效标签，按 4.4 节的分类规则合成最终攻击类型：

1. 元素维度：取优先级最高的元素（冰+火互相抵消后取剩余最高）
2. 发射维度：取优先级最高的发射模式
3. 飞行维度：取优先级最高的飞行路径
4. 命中维度：取优先级最高的命中行为
5. 四个维度的结果组合 = 最终攻击形态

#### 设计优势

- **无需穷举组合**：新增植物自带四维特效标签，自动参与协同
- **规则可预测**：孩子打到一定阶段可以理解"冰+扇形=冰冻扇形散射"
- **策略深度**：冰火抵消让植物选择有策略意义；四维正交让组合空间丰富（144 种理论形态）
- **维度独立**：追踪+穿透、扇形+爆炸等有趣组合成为可能

### 4.6 结算攻击的完整计算流程

```
结算触发（按错 / 空格 / 打满）
  ↓
1. 确定已激活植物列表（连击打满全部段数且存活的植物）
  ↓
2. 计算协同倍率：按激活存活植物数量查表得到倍率（见 4.5）
  ↓
3. 计算每棵植物的独立伤害：每棵已激活存活植物的伤害 = 该植物 attackPower × 协同倍率
   （不同植物攻击力不同，各自携带独立伤害，不做总量平分）
  ↓
4. 合成特效：收集所有已激活存活植物的四维特效标签
   → 元素维度：冰+火互相抵消后取剩余最高优先级
   → 发射维度：取最高优先级（single < burst < fan）
   → 飞行维度：取最高优先级（straight < tracking）
   → 命中维度：取最高优先级（vanish < chain < pierce < explode）
   → 四维组合得到最终攻击形态
  ↓
5. 发射弹道：每棵已激活植物各自发射独立弹道（各自的射击动画）
   发射模式由 Spread 维度决定（single/burst/fan）
   每颗弹道携带该植物的独立伤害，统一使用合成后的攻击形态
   （弹道飞行期间玩家可继续打字，僵尸继续移动和啃食）
  ↓
6. 飞行与命中：弹道按 Flight 维度飞行（straight 直线 / tracking 追踪）
   碰到僵尸后按 Impact 维度处理（vanish 消失 / chain 弹跳 / pierce 穿透 / explode 爆炸）
  ↓
7. 伤害结算：对每只命中的僵尸独立计算伤害，超杀伤害不溢出到其他僵尸
   → 同时应用元素效果（ice 减速 / fire 灼烧 / electric 传导 / stun 眩晕 / knockback 击退）
  ↓
8. 如果是打满链条：额外触发存活植物回血 + 阵亡植物复活
   （复活的植物不参与上面第 1-7 步的攻击）
  ↓
9. 连击归零，链条回到第一棵植物
```

## 五、僵尸系统

### 5.1 僵尸属性

```
僵尸 {
  id: string            // 唯一标识
  type: string          // 类型
  hp: number            // 血量
  speed: number         // 移动速度
  chewSpeed: number     // 啃植物速度（每秒扣多少血）
  reward: object        // 击杀奖励（可扩展）
}
```

### 5.2 初版僵尸类型

| 僵尸类型 | 血量 | 速度 | 啃速 | 特点 | 解锁时机 |
|----------|------|------|------|------|----------|
| 普通僵尸 | 低 | 慢 | 慢 | 基础敌人 | 初始 |
| 胖僵尸 | 高 | 慢 | 慢 | 皮厚，需要更多伤害击杀 | 第 2 阶段 |
| 旗手僵尸 | 低 | 稍快 | 快 | 速度快，啃得也快，留给孩子的反应时间短 | 第 3 阶段 |

> 更多僵尸类型可通过策略配置新增，不改动核心代码。

### 5.3 僵尸行为

```
生成（右侧屏幕外）
  ↓
向左移动
  ↓
到达最右侧植物 → 停下来啃
  ↓
啃掉当前植物（血量归零）→ 继续前进啃下一棵
  ↓
啃穿所有植物 → 走出屏幕左侧 → 放过 +1
```

在任何阶段（移动中、啃植物中）都可以被结算攻击命中。

### 5.4 僵尸状态效果

僵尸可以同时承受多种状态效果：

| 状态 | 来源元素 | 行为 |
|------|---------|------|
| slow | ice | 移动和啃食速度降低，持续一段时间 |
| burn | fire | 每秒受灼烧伤害，持续一段时间 |
| stun | stun | 完全停止移动和啃食，持续一段时间 |

**状态规则**：
- 同种状态不叠加，后施加的刷新持续时间
- 不同种状态可共存（一只僵尸可以同时被减速和灼烧）
- knockback 是一次性位移，不作为持续状态，命中时直接修改僵尸位置（不推出屏幕右边界）
- electric 传导是瞬时伤害，不产生持续状态

### 6.2 通关规则

- 每阶段包含固定数量的关卡（具体数值由策略配置）
- 通关所有关卡 → 进入下一阶段，解锁新植物
- 本关失败 → 重打当前关（不丢全局阶段进度）

### 6.3 核心成长循环

```
通关阶段 → 解锁新植物 → 链条加长，连击上限提升
                            ↓
                     协同组合更丰富 → 攻击形态更多样
                            ↓
                     但僵尸也更强 → 需要更好的指法和策略
```

                      │ 驱动

```

**新增内容不改核心代码**：

- 新植物 → 加一条植物配置
- 新僵尸 → 加一条僵尸配置
- 新协同 → 加一条协同规则
- 调数值 → 改配置参数

### 10.3 核心数据模型

#### 游戏状态

```
GameState {
  currentStage: number          // 当前指法阶段
  currentLevel: number          // 当前关卡
  currentWave: number           // 当前波次

  missedLimit: number           // 放过上限
  zombies: Zombie[]             // 场上所有僵尸

}
```

#### 单路状态

```

## 十一、实现优先级

### P0 - 最小可玩版本

| 模块 | 内容 | 完成标准 |
|------|------|----------|
| 单路僵尸 + 打字攻击 | 僵尸走来，打字推进连击，结算攻击僵尸 | 能打字触发植物攻击消灭僵尸 |
| 植物链条 + 连击系统 | 可变段数链条，连击推进 | 连击正确推进，按错/空格正确结算 |
| 结算攻击计算 | 已激活植物攻击力求和 | 攻击力正确计算 |
| 僵尸啃植物 | 植物血量，啃→阵亡→继续 | 僵尸能啃穿植物链 |
| 植物复活/回血 | 打满链条触发 | 复活和回血正确执行 |
| 指法提示 | 虚拟键盘高亮 | 能看到该按哪个键 |
| 波次基础流程 | 开始→打完→下一波/失败 | 能完整打完一关 |

### P1 - 核心体验完善

| 模块 | 内容 |
|------|------|
| 协同攻击系统 | 四维特效合成（Element × Spread × Flight × Impact） |
| 即时反馈 | 音效 + 命中特效 + 连击切换动画 |
| 波次总结 | 每波结束展示数据和称号 |
| 僵尸状态系统 | slow/burn/stun 状态效果 + knockback 位移 |

### P2 - 难度与深度

| 模块 | 内容 |
|------|------|
| 多路系统 | 2 路、3 路，独立链条 |
| 难度档位 | 简单/普通/困难，放过上限配置 |
| 自适应难度 | 字母出现频率智能调整 |
| 僵尸类型丰富化 | 胖僵尸、旗手等 |

### P3 - 长期动力

| 模块 | 内容 |
|------|------|
| 植物解锁 + 图鉴 | 通关解锁，收集展示 |
| 成就系统 | 各种里程碑徽章 |
| 植物自定义排列 | 让孩子选择植物顺序 |
| 更多协同规则 | 丰富组合变化 |
