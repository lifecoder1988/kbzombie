# 键盘侠大战僵尸 - 游戏设计文档

> **目标用户**：小学三年级（8-9 岁）
> **核心理念**：在游戏中建立正确指法习惯，让孩子觉得"好玩"而非"被考试"
> **技术栈**：React + Canvas，桌面端浏览器，localStorage 存储

---

## 一句话描述

僵尸从右边走来，孩子打字触发植物攻击，连击越长激活的植物越多，结算时所有已激活植物联合攻击，打满整条连击链触发最强协同大招并复活阵亡植物。

## 视觉风格

- 植物大战僵尸经典风格，卡通蠢萌，不恐怖
- 横版草坪场景：左侧植物阵地，右侧僵尸进攻方向
- 当前连击位置的植物上方显示待输入的字母/单词

## 核心循环

```
打字命中 → 连击推进植物链 → 结算时所有已激活植物联合攻击
    ↓                              ↓
  连击越长 → 激活植物越多 → 协同加成越强 → 攻击形态越丰富
    ↓
  打满链条 → 最强协同攻击 + 阵亡植物复活 + 存活植物回血
```

## 技术架构

### 技术栈

| 维度 | 方案 |
|------|------|
| 框架 | React（单页应用） |
| 渲染 | Canvas（横版游戏场景）+ DOM（UI 层） |
| 音效 | Web Audio API（初版简单音效） |
| 数据存储 | 浏览器 localStorage |
| 键盘输入 | keydown 事件（需处理中文输入法干扰） |
| 适配 | 仅桌面端（需实体键盘） |

### 架构原则：机制与策略分离

```
┌─────────────────────────────────────────────────┐
│                  策略配置层                        │
│  关卡数据 / 波次配置 / 植物属性 / 僵尸属性         │
│  协同规则 / 难度参数 / 字母出现规则                 │
│  （JSON 或 JS 配置文件，改配置不改代码）            │
└─────────────────────┬───────────────────────────┘
                      │ 读取配置
┌─────────────────────▼───────────────────────────┐
│                  游戏逻辑层                        │
│  连击系统 / 植物链条 / 结算计算 / 协同匹配          │
│  出题系统 / 僵尸行为 / 碰撞判定 / 血量管理 / 波次管理│
│  （核心玩法逻辑，依赖引擎层接口）                    │
├─────────────────────┬───────────────────────────┤
│                  游戏引擎层                        │
│  Game Loop / 场景管理 / 实体管理 / 渲染 / 输入 / 音效│
│  （通用游戏能力，不感知具体玩法）                     │
└─────────────────────┬───────────────────────────┘
                      │ 驱动
┌─────────────────────▼───────────────────────────┐
│                  表现层                            │
│  Canvas 渲染 / 动画 / 音效 / UI 组件               │
│  键盘输入 / 虚拟键盘显示                            │
└─────────────────────────────────────────────────┘
```

**新增内容不改核心代码**：

- 新植物 → 加一条植物配置
- 新僵尸 → 加一条僵尸配置
- 新协同 → 加一条协同规则
- 调数值 → 改配置参数

## 实现优先级

### P0 - 最小可玩版本

| 模块 | 内容 | 完成标准 |
|------|------|----------|
| 单路僵尸 + 打字攻击 | 僵尸走来，打字推进连击，结算攻击僵尸 | 能打字触发植物攻击消灭僵尸 |
| 植物链条 + 连击系统 | 可变段数链条，连击推进 | 连击正确推进，按错/空格正确结算 |
| 结算攻击计算 | 已激活植物攻击力求和 | 攻击力正确计算 |
| 僵尸啃植物 | 植物血量，啃→阵亡→继续 | 僵尸能啃穿植物链 |
| 植物复活/回血 | 打满链条触发 | 复活和回血正确执行 |
| 指法提示 | 虚拟键盘高亮 | 能看到该按哪个键 |
| 波次基础流程 | 开始→打完→下一波/失败 | 能完整打完一关 |

### P1 - 核心体验完善

| 模块 | 内容 |
|------|------|
| 协同攻击系统 | 四维特效合成（Element × Spread × Flight × Impact） |
| 即时反馈 | 音效 + 命中特效 + 连击切换动画 |
| 波次总结 | 每波结束展示数据和称号 |
| 僵尸状态系统 | slow/burn/stun 状态效果 + knockback 位移 |

### P2 - 难度与深度

| 模块 | 内容 |
|------|------|
| 多路系统 | 2 路、3 路，独立链条 |
| 难度档位 | 简单/普通/困难，放过上限配置 |
| 自适应难度 | 字母出现频率智能调整 |
| 僵尸类型丰富化 | 胖僵尸、旗手等 |

### P3 - 长期动力

| 模块 | 内容 |
|------|------|
| 植物解锁 + 图鉴 | 通关解锁，收集展示 |
| 成就系统 | 各种里程碑徽章 |
| 植物自定义排列 | 让孩子选择植物顺序 |
| 更多协同规则 | 丰富组合变化 |
