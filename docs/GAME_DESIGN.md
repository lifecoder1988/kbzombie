# 键盘侠大战僵尸 - 游戏设计文档

> **目标用户**：小学三年级（8-9 岁）
> **核心理念**：在游戏中建立正确指法习惯，让孩子觉得"好玩"而非"被考试"
> **技术栈**：React + Canvas，桌面端浏览器，localStorage 存储

---

## 一、游戏概述

### 1.1 一句话描述

僵尸从右边走来，孩子打字触发植物攻击，连击越长激活的植物越多，结算时所有已激活植物联合攻击，打满整条连击链触发最强协同大招并复活阵亡植物。

### 1.2 视觉风格

- 植物大战僵尸经典风格，卡通蠢萌，不恐怖
- 横版草坪场景：左侧植物阵地，右侧僵尸进攻方向
- 当前连击位置的植物上方显示待输入的字母/单词

### 1.3 核心循环

```
打字命中 → 连击推进植物链 → 结算时所有已激活植物联合攻击
    ↓                              ↓
  连击越长 → 激活植物越多 → 协同加成越强 → 攻击形态越丰富
    ↓
  打满链条 → 最强协同攻击 + 阵亡植物复活 + 存活植物回血
```

## 二、核心机制

### 2.1 打字攻击

- 僵尸从右侧缓慢走向左侧植物阵地
- 当前连击位置的植物上方显示待输入的字母（由出题系统按当前阶段的字母池生成）
- 按对字母 → 连击 +1，链条推进，下一个字母出现在对应植物上方
- 按错 → 触发一次结算（按当前已激活植物计算攻击），连击归零
- 按空格 → 主动触发结算，效果同上
- 结算触发后，已激活植物**发射弹道攻击**，弹道飞行一段时间后命中僵尸（非瞬时伤害）
- 默认命中当前路最前面的僵尸；穿透/范围攻击可命中多只（见攻击类型框架）
- 弹道飞行期间僵尸继续移动和啃食
- **弹道飞行期间玩家可以继续打字**，多组弹道可同时在空中飞行
- 每次结算的目标按**发射时的场上状态**快照选择，不等前一发命中

#### 有效输入规则

| 按键类型 | 处理方式 |
|----------|----------|
| 当前字母池内的字母 | 正常匹配，按对推进连击，按错触发结算 |
| 字母池外的可见字符 | 视为按错，触发结算 |
| 空格 | 主动触发结算 |
| 功能键（Shift/Ctrl/Alt 等） | 忽略，不产生任何效果 |
| 连击为 0 时按错 | 忽略，不触发空结算 |
| 场上无僵尸时结算 | 正常结算流程但弹道无目标，连击归零（不浪费结算动画） |

> 初版只接受字母键。后续高阶阶段可扩展数字和符号。

### 2.2 连击与植物链条

#### 链条结构

植物从左到右排列，每棵植物占据一段连击区间。**每棵植物的段数由配置决定，不固定**。

```
示例（段数分别为 4、4、8）：
[豌豆射手:4段] → [寒冰射手:4段] → [火炬树桩:8段]
  连击 1-4          连击 5-8         连击 9-16
```

链条总长 = 各植物段数之和。

#### 连击推进规则

| 操作 | 效果 |
|------|------|
| 按对字母 | 连击 +1，推进到链条中对应的植物段 |
| 按错字母（连击 > 0） | 触发结算攻击，连击归零 |
| 按错字母（连击 = 0） | 忽略，不触发空结算 |
| 按空格（连击 > 0） | 主动触发结算攻击，连击归零 |
| 按空格（连击 = 0） | 忽略 |
| 连击打满链条 | 自动触发最强结算（全植物协同）+ 复活/回血，连击归零 |

#### 结算攻击计算

每次结算（按错/空格/打满）的攻击力 = **所有已激活的存活植物** 的攻击力之和 + 协同加成。

**激活条件：连击打满该植物的全部段数**。仅仅"经过"但未打满的植物不算激活，不贡献攻击力。这意味着中途按错会浪费未打满植物的进度，鼓励玩家尽量多打再结算。

```
示例：链条 [豌豆:4段] → [寒冰:4段] → [火炬:8段]
连击到第 10 下按错 →
  豌豆(4/4 满 ✓) + 寒冰(4/4 满 ✓) + 火炬(2/8 未满 ✗)
  已激活: 豌豆 + 寒冰（火炬未打满，不参与）
  结算 = 豌豆攻击力 + 寒冰攻击力 + 协同加成

连击到第 6 下按错 →
  豌豆(4/4 满 ✓) + 寒冰(2/4 未满 ✗)
  已激活: 仅豌豆（寒冰未打满，不参与）
  结算 = 豌豆攻击力（无协同，只有 1 棵）
```

阵亡植物不贡献攻击力（即使打满了也不算）：

```
示例：链条 [豌豆:活] → [寒冰:活] → [火炬:☠️]
连击到第 16 下打满 →
  豌豆(4/4 满, 活 ✓) + 寒冰(4/4 满, 活 ✓) + 火炬(8/8 满, ☠️ 无贡献)
  结算 = 豌豆攻击力 + 寒冰攻击力（火炬阵亡，不贡献攻击也不触发协同）
  打满后火炬复活，但不参与本次结算
```

### 2.3 植物阵亡与复活

#### 植物血量

- 每棵植物有独立血量
- 僵尸到达植物位置后开始啃，持续扣血
- 血量归零 → 植物阵亡，僵尸继续前进啃下一棵
- 正在被啃的僵尸仍可被打字击杀，击杀后植物保住（残血）

#### 回血与复活

打满整条连击链时：

| 植物状态 | 效果 |
|----------|------|
| 存活（满血或残血） | 回血（回血量可配置） |
| 阵亡 | 复活（复活后的血量可配置） |

**关键规则**：复活的植物**不参与本次结算攻击**，从下次连击开始才贡献攻击力。存活植物正常参与本次结算。

#### 阵亡后的链条

植物阵亡后链条结构不变，阵亡植物的连击段变为"空转"：

- 阵亡植物呈**倒伏/枯萎**状态，但仍占据链条位置
- 该植物上方**仍然显示待输入字母**，玩家仍需正确输入才能推进连击
- 连击数仍然正常增长
- 该段不产生攻击输出
- 不触发涉及该植物的协同效果
- 打满整条链条可复活该植物（视觉上用灰色/半透明字母暗示"空转"）

### 2.4 僵尸啃植物机制

植物从左到右排列，**最强植物在最右边（最靠近僵尸进攻方向）**。

```
僵尸从右往左啃：
僵尸 →→→ [大喷菇] → 啃掉 → [火炬树桩] → 啃掉 → [寒冰射手] → ...
          最强，最先被啃         ←  越往左越安全
```

- 僵尸到达植物位置后停下来啃，啃的过程中可被击杀
- **多只僵尸可以同时啃同一棵植物**，植物承受的伤害叠加（DPS 翻倍）
- 啃掉当前植物后继续前进到下一棵
- 啃穿整排所有植物并走出屏幕左侧 → 放过计数 +1

### 2.5 通关与失败

| 事件 | 后果 |
|------|------|
| 僵尸到达最右侧植物 | 开始啃，僵尸停下 |
| 啃掉一棵植物 | 继续前进啃下一棵 |
| 啃穿所有植物走出屏幕 | 放过计数 +1 |
| 放过数达到上限 | **本关失败，重打当前关**（所有植物状态重置为满血） |
| 所有波次完成 | 关卡通关 |

> 设计意图：重打整关而非当前波，避免因累积植物损伤造成无法翻盘的死局。通过控制每关波次数量（建议 3-5 波）来控制单次失败的时间成本。

**放过上限按难度档位配置**（同一难度下所有关卡一致）：

| 难度 | 放过上限 | 说明 |
|------|----------|------|
| 简单 | 可配置（建议 5） | 容错大，适合练习 |
| 普通 | 可配置（建议 3） | 标准体验 |
| 困难 | 可配置（建议 1） | 高手挑战 |

### 2.6 波次机制

- 每关包含多波僵尸（建议 3-5 波）
- 每波约 15-20 只僵尸，耗时约 2-3 分钟
- 一局总时长约 10-15 分钟

**波次之间**：

| 项目 | 是否重置 |
|------|----------|
| 连击进度 | 归零 |
| 放过计数 | **不归零**，整关累计 |
| 植物血量 | **不恢复**，保持上一波结束时的状态 |
| 阵亡植物 | **不复活**，需在下一波通过打满连击复活 |

> 设计意图：前面打得好，后面有优势；前面打得差，后面压力更大。持续后果让每一波的表现都有意义。

**波次过渡**：

- 波次之间有短暂停顿（具体秒数待定）
- 停顿期间可显示本波简要数据（消灭数、最长连击等）
- 停顿结束后自动进入下一波

> 过渡停顿给孩子喘息空间，也是正反馈时刻。具体时长和展示内容后续迭代确定。

## 三、多路系统

### 3.1 路数递进

| 阶段 | 路数 | 说明 |
|------|------|------|
| 初期 | 1 路 | 专注指法，不分心 |
| 中期 | 2 路 | 增加战场判断 |
| 后期 | 3 路 | 多线程注意力管理 |

### 3.2 每路独立

- 每路有**自己独立的植物链条**（相同的植物组合，各自独立状态）
- 连击进度独立
- 植物血量和生死状态独立
- A 路打满连击只影响 A 路的植物

### 3.3 操作方式与选路规则

只有两个操作：

| 按键 | 功能 |
|------|------|
| 字母键 | 打字攻击，同时隐含选路 |
| 空格键 | 主动释放**当前路**连击（仅结算当前路，连击归零） |

**"当前路"定义**：最近一次成功推进连击的那条路。初始状态无当前路。

**流程**：

1. 各路当前连击位置的植物各自显示一个待输入字母
2. 孩子打字 → 系统匹配到显示该字母的那路 → 连击推进该路，该路成为"当前路"
3. 想切路 → 按空格释放当前路 → 打下一个字母自动匹配到新路
4. 打满某路 → 自动结算，之后下一个字母自然选路

**界面上须有明显提示**指示当前在哪一路（高亮/边框/箭头等）。

#### 多路按错判定

| 场景 | 处理 |
|------|------|
| 按的字母匹配到某路的当前字母 | 推进该路连击，该路成为当前路 |
| 按的字母不匹配任何路的当前字母 | 视为按错，触发**当前路**结算（连击 > 0 时），连击归零 |
| 按的字母不匹配任何路 + 无当前路（连击 = 0） | 忽略 |

### 3.4 出题规则

- **各路当前显示的首位字母互不重复**（避免歧义）
- 字母由出题系统按当前阶段的字母池生成，显示在对应植物上方

### 3.5 结算攻击目标

- 默认攻击：命中当前路**最前面**的僵尸（最靠近植物的）
- 穿透/范围攻击（由特效合成决定）：可命中本路多只僵尸
- 攻击类型由特效系统自动合成（见 4.4 特效系统）

## 四、植物系统

### 4.1 植物属性

每棵植物有以下可配置属性：

```
植物 {
  id: string               // 唯一标识
  name: string             // 显示名称
  comboSegment: number     // 占据的连击段数（4、8、16...）
  attackPower: number      // 基础攻击力
  element: string          // 元素特效（normal / ice / fire）
  trajectory: string       // 弹道特效（direct / pierce / area / tracking）
  hp: number               // 血量上限
  chainPosition: number    // 链条中的位置（从左到右）
  unlockStage: number      // 在哪个指法阶段解锁
}
```

### 4.2 初版植物设计

| 植物 | 链条位置 | 连击段数 | 元素 | 弹道 | 攻击特点 | 解锁阶段 |
|------|----------|----------|------|------|----------|----------|
| 豌豆射手 | 第 1 位 | 4 | 普通 | 直射 | 基础伤害，无特效 | 第 1 阶段（默认） |
| 寒冰射手 | 第 2 位 | 4 | 冰冻 | 直射 | 附带减速 | 第 2 阶段 |
| 双发射手 | 第 3 位 | 4 | 普通 | 直射 | 纯高攻击力 | 第 3 阶段 |
| 火炬树桩 | 第 4 位 | 8 | 火焰 | 直射 | 附带灼烧 | 第 4 阶段 |
| 大喷菇 | 第 5 位 | 16 | 普通 | 辐射 | 范围攻击 | 第 5 阶段 |
| 猫尾草 | 第 6 位 | 待定 | 普通 | 追踪 | 锁定离植物最近的僵尸 | 第 6 阶段 |

> 段数和属性均为初版建议值，由策略配置决定，可随时调整。

### 4.3 植物排列

**最强植物在最右边（最靠近僵尸）**。链条从左到右依次是从弱到强。

```
← 安全侧                                          危险侧 →
[豌豆射手] → [寒冰射手] → [双发射手] → [火炬树桩] → [大喷菇] → [猫尾草]
  最弱，最安全                                        最强，最先被啃
```

初版按解锁顺序固定排列。**后续可扩展**：让孩子自定义植物顺序，增加策略深度。

### 4.4 特效系统

每棵植物自带特效标签，协同时特效按分类规则叠加，自动产生组合攻击效果，**无需穷举配置具体植物组合**。

#### 特效分类

特效分为**两个正交维度**，不同维度之间自由叠加，同维度内互斥取优：

| 维度 | 说明 | 可选值 |
|------|------|--------|
| **元素**（影响伤害属性/附加效果） | 同维度互斥，取优先级最高的 | 普通(normal)、冰冻(ice)、火焰(fire) |
| **弹道**（影响命中范围/轨迹） | 同维度互斥，取优先级最高的 | 直射(direct)、穿透(pierce)、辐射(area)、追踪(tracking) |

> 两个维度未来可独立扩展，新增维度不影响已有维度的逻辑。

#### 同维度优先级

**元素优先级**（从低到高）：

```
普通(normal) < 冰冻(ice) = 火焰(fire)
```

特殊规则：冰冻 + 火焰同时存在 → **互相抵消，回退为普通**。

**弹道优先级**（从低到高）：

```
直射(direct) < 追踪(tracking) < 穿透(pierce) < 辐射(area)
```

#### 元素附加效果

| 元素 | 附加效果 | 数值 |
|------|----------|------|
| 普通 | 无 | — |
| 冰冻 | 命中后减速（降低移动速度和啃食速度） | 减速比例、持续时间待定 |
| 火焰 | 命中后灼烧（持续伤害） | 灼烧 DPS、持续时间待定 |

> 附加效果的具体数值待平衡调整时确定。框架先搭好，代码预留接口。

#### 弹道类型与行为

弹道是**真实的游戏实体**，有位置、速度、碰撞体积，由引擎的实体系统管理生命周期，每帧参与 update/render 循环。

**直射弹道**：
- 从植物位置水平直线飞向右侧
- 碰到第一只僵尸 → 命中，弹道消失
- 飞出屏幕右边界 → 弹道消失（未命中）

**追踪弹道**：
- 发射时锁定目标（离植物最近的僵尸，可跨路）
- 每帧调整飞行方向朝向目标当前位置（僵尸在移动，弹道轨迹是曲线）
- 有最大转向速率（`trackingTurnRate`，默认 π 弧度/秒），不能瞬间转弯，形成弧线
- 碰到目标僵尸 → 命中，弹道消失
- 目标在飞行途中死亡 → 弹道沿最后方向继续飞行，可碰撞途中其他僵尸；飞出屏幕则消失

**穿透弹道**：
- 从植物位置水平直线飞向右侧（同直射）
- 碰到僵尸 → 命中，**弹道不消失，继续飞行**
- 可命中直线上所有僵尸（本路），直到飞出屏幕
- 每只僵尸只被同一发穿透弹命中一次

**辐射弹道**：
- 从植物位置向前方**扇形散射发射多颗子弹**（数量由 `areaBulletCount` 配置，默认 5）
- 扇形总角度由 `areaSpreadAngle` 配置（默认 π/3 即 60°），正前方（0°）**始终有一颗子弹**
- 每颗子弹独立飞行，有各自的方向和碰撞
- 每颗子弹的伤害 = 该植物伤害 × `areaDamageDecay`（衰减系数，默认 1.0 即无衰减）
- 子弹之间有角度间隔，范围内的僵尸**不一定全部命中**（有空隙）
- 每颗子弹碰到僵尸 → 命中该僵尸，子弹消失
- 子弹数量越多、扇形越密，覆盖越好，但不保证无遗漏

#### 碰撞判定

- 弹道和僵尸都有碰撞体积（矩形 AABB）
- 每帧检测弹道与僵尸的碰撞（引擎层通用能力，不感知具体玩法）
- 命中后对该僵尸独立计算伤害，超杀不溢出
- 同一只僵尸可被多发弹道命中（来自不同次结算的弹道）

#### 弹道命中规则汇总

| 弹道 | 飞行方式 | 命中后 | 范围 | 关键特征 |
|------|----------|--------|------|----------|
| 直射 | 水平直线 | 消失 | 本路 | 命中第一只 |
| 追踪 | 曲线追踪目标 | 消失 | **跨路** | 每帧调整方向，目标死亡后沿惯性飞行 |
| 穿透 | 水平直线 | 继续飞行 | 本路 | 穿过所有僵尸 |
| 辐射 | 扇形散射多颗 | 每颗独立消失 | 本路 | 有空隙，不保证全覆盖 |

#### 特效合成示例

| 激活植物 | 元素层 | 弹道层 | 最终攻击 |
|----------|--------|--------|----------|
| 豌豆 | 普通 | 直射 | 普通直射（基础攻击） |
| 寒冰 + 大喷菇 | 冰冻 | 辐射 > 直射 | **冰冻范围攻击** |
| 火炬 + 大喷菇 | 火焰 | 辐射 > 直射 | **火焰范围攻击** |
| 火炬 + 猫尾草 | 火焰 | 追踪 > 直射 | **火焰追踪弹** |
| 寒冰 + 火炬 | 冰火抵消→普通 | 直射 | **普通直射**（元素浪费） |
| 寒冰 + 火炬 + 大喷菇 | 冰火抵消→普通 | 辐射 | **普通范围攻击** |
| 火炬 + 大喷菇 + 猫尾草 | 火焰 | 辐射 > 追踪 > 直射 | **火焰范围攻击** |

> 加新植物 = 加一个特效标签，自动参与协同，不需要配置具体组合。

### 4.5 协同攻击系统

#### 触发条件

结算时激活了 **2 棵及以上存活植物**即触发协同。单棵植物结算只使用自身特效，不算协同。

#### 协同效果（两层）

**第一层：攻击力加成** — 由激活植物数量决定，与具体植物种类无关：

| 激活植物数 | 攻击力倍率 |
|-----------|-----------|
| 1 棵 | ×1.0（无加成） |
| 2 棵 | ×待定（建议 1.2） |
| 3 棵 | ×待定（建议 1.5） |
| 4 棵 | ×待定（建议 1.8） |
| 5 棵 | ×待定（建议 2.2） |
| 6 棵（满链） | ×待定（建议 3.0） |

> 倍率公式待平衡调整时确定。可以是固定查表，也可以是连续公式。

**第二层：特效合成** — 收集所有已激活存活植物的特效标签，按 4.4 节的分类规则合成最终攻击类型：

1. 元素维度：取优先级最高的元素（冰+火抵消）
2. 弹道维度：取优先级最高的弹道
3. 两个维度的结果组合 = 最终攻击形态

#### 设计优势

- **无需穷举组合**：新增植物自带特效标签，自动参与协同
- **规则可预测**：孩子打到一定阶段可以理解"冰+范围=冰冻范围攻击"
- **策略深度**：冰火抵消让植物排列/激活顺序有策略意义

### 4.6 结算攻击的完整计算流程

```
结算触发（按错 / 空格 / 打满）
  ↓
1. 确定已激活植物列表（连击打满全部段数且存活的植物）
  ↓
2. 计算协同倍率：按激活存活植物数量查表得到倍率（见 4.5）
  ↓
3. 计算每棵植物的独立伤害：每棵已激活存活植物的伤害 = 该植物 attackPower × 协同倍率
   （不同植物攻击力不同，各自携带独立伤害，不做总量平分）
  ↓
4. 合成特效：收集所有已激活存活植物的特效标签
   → 元素维度：取最高优先级（冰+火抵消）
   → 弹道维度：取最高优先级
   → 组合得到最终攻击类型
  ↓
5. 发射弹道：每棵已激活植物各自发射独立弹道（各自的射击动画）
   每颗弹道携带该植物的独立伤害，统一使用合成后的攻击类型飞向目标
   （弹道飞行期间玩家可继续打字，僵尸继续移动和啃食）
  ↓
6. 命中判定：弹道到达后，根据弹道类型确定命中哪些僵尸
   - 直射：命中当前路最前方 1 只
   - 追踪：命中离植物最近的 1 只（可跨路）
   - 穿透：命中弹道直线上所有僵尸（本路）
   - 辐射：命中目标点半径内所有僵尸（本路）
  ↓
7. 伤害结算：对每只命中的僵尸独立计算伤害，超杀伤害不溢出到其他僵尸
   → 同时应用元素附加效果（冰冻减速 / 火焰灼烧）
  ↓
8. 如果是打满链条：额外触发存活植物回血 + 阵亡植物复活
   （复活的植物不参与上面第 1-7 步的攻击）
  ↓
9. 连击归零，链条回到第一棵植物
```

## 五、僵尸系统

### 5.1 僵尸属性

```
僵尸 {
  id: string            // 唯一标识
  type: string          // 类型
  hp: number            // 血量
  speed: number         // 移动速度
  chewSpeed: number     // 啃植物速度（每秒扣多少血）
  reward: object        // 击杀奖励（可扩展）
}
```

### 5.2 初版僵尸类型

| 僵尸类型 | 血量 | 速度 | 啃速 | 特点 | 解锁时机 |
|----------|------|------|------|------|----------|
| 普通僵尸 | 低 | 慢 | 慢 | 基础敌人 | 初始 |
| 胖僵尸 | 高 | 慢 | 慢 | 皮厚，需要更多伤害击杀 | 第 2 阶段 |
| 旗手僵尸 | 低 | 稍快 | 快 | 速度快，啃得也快，留给孩子的反应时间短 | 第 3 阶段 |

> 更多僵尸类型可通过策略配置新增，不改动核心代码。

### 5.3 僵尸行为

```
生成（右侧屏幕外）
  ↓
向左移动
  ↓
到达最右侧植物 → 停下来啃
  ↓
啃掉当前植物（血量归零）→ 继续前进啃下一棵
  ↓
啃穿所有植物 → 走出屏幕左侧 → 放过 +1
```

在任何阶段（移动中、啃植物中）都可以被结算攻击命中。

## 六、指法阶段与进度系统

### 6.1 阶段设计

| 阶段 | 练习内容 | 解锁植物 | 路数 | 新增僵尸 |
|------|----------|----------|------|----------|
| 第 1 阶段 | 基准键 F / J | 豌豆射手（默认） | 1 路 | 普通僵尸 |
| 第 2 阶段 | 中间行 ASDF JKL; | 寒冰射手 | 1 路 | 胖僵尸 |
| 第 3 阶段 | 上行 QWER UIOP | 双发射手 | 1 路 | 旗手僵尸 |
| 第 4 阶段 | 下行 ZXCV NM | 火炬树桩 | 2 路 | — |
| 第 5 阶段 | 全键盘混合 | 大喷菇 | 3 路 | — |
| 第 6 阶段 | 简单单词 | 猫尾草 | 3 路 | 待设计 |
| 第 7 阶段 | 短句 / 拼音 | 待设计 | 3 路 | 待设计 |

### 6.2 通关规则

- 每阶段包含固定数量的关卡（具体数值由策略配置）
- 通关所有关卡 → 进入下一阶段，解锁新植物
- 本关失败 → 重打当前关（不丢全局阶段进度）

### 6.3 核心成长循环

```
通关阶段 → 解锁新植物 → 链条加长，连击上限提升
                            ↓
                     协同组合更丰富 → 攻击形态更多样
                            ↓
                     但僵尸也更强 → 需要更好的指法和策略
```

```
│                  表现层                            │

│  键盘输入 / 虚拟键盘显示                            │
└─────────────────────────────────────────────────┘
```

**新增内容不改核心代码**：

- 新植物 → 加一条植物配置
