## 一、僵尸属性

```
僵尸 {
  id: string            // 唯一标识
  name: string          // 显示名称
  hp: number            // 血量
  speed: number         // 移动速度（像素/秒）
```

## 三、僵尸行为

```
生成（右侧屏幕外）
  ↓
向左移动
  ↓
到达最右侧植物 → 停下来啃
  ↓
啃掉当前植物（血量归零）→ 继续前进啃下一棵
  ↓
啃穿所有植物 → 走出屏幕左侧 → 放过 +1
```

在任何阶段（移动中、啃植物中）都可以被结算攻击命中。

---

## 四、僵尸状态效果

僵尸可以同时承受多种状态效果：

| 状态 | 来源元素 | 行为 |
|------|---------|------|
| slow | ice | 移动和啃食速度降低，持续一段时间 |
| burn | fire | 每秒受灼烧伤害，持续一段时间 |
| stun | stun | 完全停止移动和啃食，持续一段时间 |

**状态规则**：
- 同种状态不叠加，后施加的刷新持续时间
- 不同种状态可共存（一只僵尸可以同时被减速和灼烧）
- knockback 是一次性位移，不作为持续状态，命中时直接修改僵尸位置（不推出屏幕右边界）
- electric 传导是瞬时伤害，不产生持续状态

### 通关规则

- 每阶段包含固定数量的关卡（具体数值由策略配置）
- 通关所有关卡 → 进入下一阶段，解锁新植物
- 本关失败 → 重打当前关（不丢全局阶段进度）

### 核心成长循环

```
通关阶段 → 解锁新植物 → 链条加长，连击上限提升
                            ↓
                     协同组合更丰富 → 攻击形态更多样
                            ↓
                     但僵尸也更强 → 需要更好的指法和策略
```

## 七、难度自适应（后续迭代）

初版：随机出当前阶段范围内的字母。

后续迭代方向：

- 为每个字母/单词维护熟练度分数
- 不熟悉的字母出现频率更高
- 已掌握的字母降低频率但不完全消失
- 具体算法待核心机制跑通后设计

## 八、反馈与激励

### 即时反馈（每次按键）

| 事件 | 反馈 |
|------|------|
| 按对字母 | 连击条增长 + 按键音效 + 植物上方字母切换到下一个 |
| 连击推进到新植物 | 新植物激活高亮 + 音效变化 |
| 结算攻击（按错/空格/打满） | 所有已激活植物联合射击动画 + 命中僵尸 |
| 协同触发 | 协同专属特效（火焰、冰霜、爆炸等） |
| 打满链条 | 全屏大招特效 + 复活/回血动画 |
| 按错 | 先结算当前威力 → 连击条归零动画 → 回到第一棵植物 |
| 僵尸啃植物 | 植物摇晃 + 血条下降 |
| 植物阵亡 | 植物碎裂/枯萎动画 |

### 短期反馈（每关结束）

> 已实现：SettlementScene（`src/scenes/SettlementScene.ts`）

- 通关展示 4 项数据：击杀僵尸、最长连击、协同攻击、放过僵尸
- 星级评价：3星（零放过）、2星（≤上限一半）、1星（通关即得）
- 趣味称号（按优先级匹配第一个命中）：
  - 「完美指挥官」：零放过 + 打满链条 ≥3 次
  - 「滴水不漏」：零放过
  - 「连击大师」：最长连击 ≥20
  - 「协同达人」：协同触发 ≥5 次
  - 「全链专家」：打满链条 ≥3 次
  - 「勇敢的键盘侠」：兜底称号
- 失败时从鼓励语池随机选一条，不显示称号
- 称号规则走配置（`src/config/settlement.ts`），阈值可调
- 手指热力图：📌 后续迭代
